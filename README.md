# ✨ Features

- 🔐 Secure JWT Authentication
- 👤 User Registration & Login
- ➕ Add New Books
- ✏️ Edit Existing Books
- ❌ Delete Books
- 📖 Track Reading Status
- 🏷️ Filter Books by Tags
- 📊 Dashboard with Statistics
- 📱 Responsive Design
- ☁️ MongoDB Atlas Database
- 🚀 Vercel Deployment

---

# 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- JWT
- bcryptjs

### Database
- MongoDB Atlas

### Deployment
- Vercel
